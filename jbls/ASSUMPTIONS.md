# 欧氏距离基线的状态约定

1. 单臂单件搬运，目标位姿固定，不重抓取、不临时放置。台面初始摆放需互不重叠。
2. 节点保存正向的已定后缀 Q 和其初始布局 X_Q；R 是其补集。
   扩展 p∈R 时：R\{p} 均在目标位置，Q 均在初始位置，p 正在取放。
   更早零件的初始位姿尚未知，但本步骤发生时它们已被取走。
3. 检查后缀内一个步骤时，其之前所有零件的目标几何由集合确定，不依赖这些零件
   内部的顺序或初始布局。因此局部候选的场景可先确定。此结论不意味着机器人
   自由连接路径已可行；未知前驱的撤离构型没有被本基线证明可接入。
4. 固定底座与桌面始终存在；空余固定件状态视为稳定终点。承载静力平衡仅用于
   稳态结构，不声称动态插入力、抓取加速度和实际装配公差满足执行要求。
5. 静力分析、A 未解出或没有已确认合格的 G 候选时不接受该分支。G 的目录即使
   部分未决，已确认合格的具体抓取仍可作为见证，但其数量不是精确的全集计数。
   候选集中的 IK/局部检查失败称为
   本预算未找到，不声称连续空间不可行。运行异常不吞掉、不转为通过。
6. 结构缓存绑定 R 和 p。局部缓存还绑定本件布局及整个已定后缀布局；同一位置
   在不同障碍环境中的失败不能全局复用。
7. cost 仅包含已指定的欧氏段。剩余估计忽略所有尚未确定的非负空手段，属于
   此代理目标的乐观估计，不是执行时间下界。有限网格与 Beam 不保证最优或完备。
